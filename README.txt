MANGO WORLD — DREAMTECH STUDIO
Installable Android web app package (PWA)

WHAT THIS IS
This package turns the Mango World browser game into an installable Progressive Web App.
It is not an APK and is not yet published in Google Play.

HOW TO INSTALL ON ANDROID
1. Host the contents of this folder on an HTTPS website (for example, GitHub Pages).
2. Open the hosted website in Chrome on your Android phone.
3. Open Chrome's ⋮ menu and choose "Install app" or "Add to Home screen".
4. Confirm. Mango World will appear as an app icon.
5. Open it once while online; the service worker caches the game for offline play.

IMPORTANT
- Do not open index.html directly from the Files app and expect installation/offline support.
- PWA installation requires HTTPS hosting (localhost is the development exception).
- This package does not include ads, tracking, or in-app purchases.
